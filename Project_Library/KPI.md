# KPI Register — Enterprise Travel & Expense Management System (ETEMS)

## Operational KPIs

| KPI Number | KPI Name | Verification Method | Criteria |
|---|---|---|---|
| KPI-OP-01 | Travel Approval SLA | Timestamp comparison between request submission and final approval recorded in the Approval Engine; measured via Audit & Compliance Layer reports | ≤ 24 Hours |
| KPI-OP-02 | Expense Settlement Time | Timestamp delta between expense submission and reimbursement payment confirmation tracked in the Reimbursement Service | ≤ 3 Business Days |
| KPI-OP-03 | Platform Availability | Azure Monitor uptime metrics and Application Insights availability tests; tracked via real-time dashboards | ≥ 99.95% |
| KPI-OP-04 | Workflow Success Rate | Percentage of end-to-end workflows (travel request to closure) completing without manual intervention; measured via event-driven pipeline telemetry | ≥ 99% |
| KPI-OP-05 | User Adoption Rate | Ratio of active platform users to total eligible employees; tracked via Employee Portal login analytics and Reporting & Analytics module | ≥ 90% |

## Governance KPIs

| KPI Number | KPI Name | Verification Method | Criteria |
|---|---|---|---|
| KPI-GV-01 | Critical Decisions Without ADR | Architecture Review Board audit of ADR Repository; verified during release gates and architecture review cycles | 0 (Zero tolerance) |
| KPI-GV-02 | Undocumented API Contracts | Automated scan of OpenAPI Registry and AsyncAPI Registry against deployed services; validated during CI/CD contract validation stage | 0 (Zero tolerance) |
| KPI-GV-03 | NFR Compliance Before Release | Pre-production NFR certification checklist sign-off covering performance, security, availability, and testability requirements | 100% |
| KPI-GV-04 | Architecture Review Gate Compliance | Mandatory architecture review board sign-off recorded before each release; tracked via Release Gates log | Mandatory (100% releases) |
| KPI-GV-05 | Production Change Approval Rate | Change Governance log audit verifying every production change has an approved change record prior to deployment | 100% |

## Reliability KPIs

| KPI Number | KPI Name | Verification Method | Criteria |
|---|---|---|---|
| KPI-RL-01 | Mean Time to Detect (MTTD) | Azure Monitor and Application Insights alerting logs; time delta between incident occurrence and first alert triggered | < 48 Hours |
| KPI-RL-02 | Mean Time to Recover (MTTR) | Incident management records; time delta between incident detection and full service restoration confirmed | < 4 Hours |
| KPI-RL-03 | Incident Resolution Time | Post-incident review reports; total time from incident raised to closure including root cause confirmation | < 24 Hours |

## Performance KPIs

| KPI Number | KPI Name | Verification Method | Criteria |
|---|---|---|---|
| KPI-PF-01 | API Response Time (P95) | Application Insights latency percentile tracking across all core APIs under load; validated via mandatory performance tests | P95 < 300ms |
| KPI-PF-02 | Page Load Time | Frontend performance monitoring via Azure Front Door and browser telemetry integrated in Employee Portal | < 2 Seconds |
| KPI-PF-03 | Approval Workflow Execution Time | End-to-end workflow timing from trigger to approval decision captured in Approval Engine event logs | < 5 Seconds |
| KPI-PF-04 | Concurrent User Support | Load testing reports simulating concurrent sessions; validated during performance certification before release | ≥ 5,000 Concurrent Users |
| KPI-PF-05 | Transaction Throughput | Performance test results measuring sustained transaction processing under peak load conditions | ≥ 100 TPS |

## Disaster Recovery KPIs

| KPI Number | KPI Name | Verification Method | Criteria |
|---|---|---|---|
| KPI-DR-01 | Recovery Point Objective (RPO) | DR drill reports verifying maximum data loss window during failover to secondary Azure region; tested periodically | ≤ 15 Minutes |
| KPI-DR-02 | Recovery Time Objective (RTO) | DR drill reports measuring time to restore full platform functionality after a simulated regional outage | ≤ 60 Minutes |
